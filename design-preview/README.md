# Matthew Gregory / Product Content Portfolio — Editorial Media Kit Direction

An original responsive design concept inspired by the modular, high-contrast and pastel-card design language of the public **Nerd or Die Content Creator Media Kit** Figma community template. This is **not a copy** of the template. It is a product case-study portfolio, and does not re-use the template's files.

## Pages
- `index.html` — Homepage with portfolio overview, four product cards, approach, About intro, and contact.
- `about.html` — Research/work narrative and personal illustration.
- `projects/floor.html` — Floor Planning Modernization.
- `projects/fire.html` — Fire & Emergency Planning.
- `projects/accident.html` — Accident Reconstruction.
- `projects/medical.html` — Healthcare Content Expansion.

## Preview
Open `index.html` directly in a browser, or run `python -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Notes
- All case studies use real diagrams and illustrations provided by the portfolio owner. Some are actual customer examples; Fire promotional artwork is explicitly labeled.
- Performance numbers are descriptive observations only, not proof that content releases caused adoption changes.
- Real product images and copy are carried over from prior portfolio work. The entire visual system and page composition are original code for this redesign concept.
- The portfolio omits internal company-wide decline figures, client contract amounts, and proprietary raw usage counts.
- All images have alt text; navigation and enlargement controls are keyboard-operable. Gallery dialog supports Escape to close.
- Before publishing, confirm permission to disclose any internal usage percentages and check that all artwork is approved for public use.

## Deploy
Copy site root files to GitHub Pages or put inside a `design-preview/` folder to compare with the current portfolio without changing it. Relative paths are used throughout.
